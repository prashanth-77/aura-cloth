# Aura Cloth Store

Aura Cloth Store is a React + TypeScript fashion storefront with product browsing, categories, cart, wishlist, authentication, profile/order history, and an admin product-management area.

## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Firebase Authentication, Firestore and Storage

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The storefront includes a local clothing catalogue so the main shopping experience works even before Firebase products are seeded.
